# Student AI Project

A small offline, rule-based study chatbot built with Python. It has prepared answers for common topics including HTML, CSS, JavaScript, Python, AI, computers, the internet, Git, math, science, and study tips.

## Run

```bash
python app.py
```

Ask about a supported topic, for example `What is HTML?`, `Python`, `AI`, or `math`. Type `help` to see supported topics, or `bye` to close the chatbot.

This beginner project works offline and uses only Python's built-in features; no extra packages are needed. Because it uses prepared answers rather than an online AI model, it cannot answer every possible question.
